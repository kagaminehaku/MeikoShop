## 📝 Giới Thiệu
**MeikoShop** là một hệ thống website thương mại điện tử được phát triển dựa trên nền tảng **ASP.NET MVC**. Dự án tập trung vào việc cung cấp một quy trình mua sắm trơn tru cho khách hàng từ khâu chọn sản phẩm đến khi thanh toán, đồng thời tích hợp các công cụ quản trị (Admin Dashboard) mạnh mẽ giúp người quản lý dễ dàng kiểm soát sản phẩm, đơn hàng và khách hàng.

## 🚀 Tính Năng Nổi Bật

### 🛍️ Phân Hệ Khách Hàng (Customer)
* **Tài khoản:** Đăng ký, đăng nhập và quản lý thông tin cá nhân.
* **Sản phẩm & Tìm kiếm:** Duyệt qua các danh mục, xem chi tiết và tìm kiếm sản phẩm theo từ khóa.
* **Giỏ hàng:** Thêm sản phẩm, thay đổi số lượng, tự động tính toán tổng tiền thanh toán.
* **Thanh toán:** Tạo đơn đặt hàng với thông tin giao hàng chi tiết.

### 🛡️ Phân Hệ Quản Trị (Admin)
* **Tổng quan (Dashboard):** Xem thống kê tổng thể về hoạt động của website.
* **Quản lý Sản phẩm & Danh mục:** Thêm mới, chỉnh sửa thông tin, giá bán và hình ảnh sản phẩm.
* **Quản lý Đơn hàng:** Kiểm tra, phê duyệt và cập nhật tình trạng giao hàng.
* **Quản lý Người dùng:** Theo dõi và quản lý thông tin các tài khoản đã đăng ký trên hệ thống.

## 🛠️ Công Nghệ Sử Dụng

* **Ngôn ngữ:** C#
* **Framework:** ASP.NET MVC 5, .NET Framework 4.8
* **Cơ sở dữ liệu:** SQL Server (LocalDB)
* **ORM:** Entity Framework 6 (Code First)
* **Giao diện (Frontend):** HTML5, CSS3, JavaScript, jQuery, Bootstrap
* **Công cụ phát triển:** Visual Studio 2022
